## 🌟 Overview

This repository features a complete, modern recreation of the iconic **[TBWA\HAKUHODO](https://www.tbwahakuhodo.co.jp/)** agency website, tailored with:
1. **Navy Blue Brand Palette**: Deep midnight navy `#040714`, obsidian cobalt accents `#172763`, and electric cyan highlights `#38bdf8`.
2. **Horizontal Narrative Scrolling**: Pinned viewport horizontal carousel powered by **GSAP** & **ScrollTrigger** showcasing agency case studies (Nissan, McDonald's Japan, Uniqlo).
3. **Disruption® Framework**: Interactive presentation of TBWA's world-renowned methodology (Convention &rarr; Disruption &rarr; Vision).
4. **Interactive Custom Cursor**: Fluid physics-based dual cursor with magnetic card hover triggers.
5. **Governed Workforce Provenance**: Coordinated and tracked by **ARISA** (Workforce Supervisor) and the SHIPS AI Workforce staff.
